- **版本**: v1.0

- **适用范围**: smart_media 项目所有 AI Agent

## 🎯 核心原则

### 1. 单 Agent 执行原则
- **强制要求**: 单轮对话中只允许一个 Agent 工作
- **角色声明**: 每次执行前必须明确声明当前 Agent 角色
- **角色切换**: 必须通过独立阶段完成，不得在同一阶段内切换

### 2. 前置条件检查
在执行任何工程操作前，必须：
1. 声明本轮唯一执行的 Agent
2. 明确列出已阅读的文件路径（至少包含）：
   - `ai/rules/agent.md`（本文件）
   - `ai/runner.md`
   - `ai/state/plan.md`
3. 若任一文件缺失，立即停止并提示"前置条件不足"
4. 在完成上述检查前不得生成任何代码或方案

### 3. 输出规范
- **统一模板**: 所有输出必须遵循统一模板结构
- **关键字段**: 若缺失关键字段需主动重写
- **禁止跳过**: 不得继续执行后续阶段直到输出完整

## 📝 代码规范

### 1. 注释要求（强制）
所有函数必须添加函数级注释，包含：
- **用途**: 函数功能说明
- **输入**: 参数说明（类型、含义、默认值）
- **输出**: 返回值说明（类型、含义）
- **副作用**: 是否修改外部状态、是否有 I/O 操作

**示例**:
```python
def scrape_media(path: str, media_type: str = "movie") -> dict:
    """
    刮削媒体文件元数据
    
    用途: 从 TMDB 获取媒体信息并生成 NFO 文件
    输入:
        - path (str): 媒体文件路径
        - media_type (str): 媒体类型，默认 "movie"，可选 "tv"
    输出:
        - dict: 包含 title, year, poster_url 等字段的元数据字典
    副作用:
        - 写入 NFO 文件到磁盘
        - 下载海报图片
        - 记录日志到数据库
    """
    pass
```

### 2. 错误处理
- **禁止静默失败**: 所有错误必须明确标记
- **限制重试**: 失败一次需明确标记 FAIL 并等待人工决策
- **不得自动重试**: 禁止 Agent 自动重试行为

### 3. 日志输出
- **真实日志**: 必须输出真实的执行日志
- **操作记录**: 记录所有关键操作
- **校验结果**: 输出校验结果

## 🔄 Workflow 执行规范

### 1. 强制使用 Workflow
- **多阶段任务**: 必须使用指定 Workflow
- **分步执行**: 每步需输出真实日志、操作与校验结果
- **禁止绕过**: 不得绕过 Workflow 流程

### 2. Workflow 格式
```markdown
---
description: [任务描述]
---

## 阶段 1: [阶段名称]
### 目标
[阶段目标]

### 步骤
1. [步骤 1]
2. [步骤 2]

### 验证
- [ ] [验证项 1]
- [ ] [验证项 2]

### 输出
- [输出文件/结果]
```

### 3. 阶段切换
- **独立阶段**: 每个阶段独立完成
- **验证通过**: 验证通过后才能进入下一阶段
- **失败处理**: 失败时标记 FAIL 并等待人工决策

---

## 🧪 测试规范

### 1. 测试优先
- **减少终端命令**: 优先使用 Python 代码完成验证
- **超时处理**: 终端执行超时需立即退出并标记失败
- **自动化测试**: 优先编写自动化测试脚本

### 2. 测试覆盖
- **核心功能**: 必须覆盖核心功能
- **边界情况**: 覆盖边界情况
- **异常处理**: 覆盖异常处理

---

## 🔒 合规要求

### 1. 安全规范
- **敏感信息**: 不得在代码中硬编码敏感信息
- **权限控制**: 遵循最小权限原则
- **数据保护**: 保护用户数据隐私

### 2. 组织规范
- **代码审查**: 关键代码需经过审查
- **文档同步**: 代码与文档保持同步
- **版本控制**: 使用 Git 进行版本控制

3. ❌ 缺少函数注释
4. ❌ 自动重试失败操作
